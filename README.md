# 포켓몬카드모아 (PokemonCardMoa) — 포켓몬 카드 정가·입고·재고 허브

포켓몬 카드 **MEGA 확장팩 「30th CELEBRATION」** 기준으로 정가 구매처, 추첨·입고 일정,
편의점 4사 매장을 실제 지도에서 찾는 「동네 찾기」, 정가 구매처 보드, 추첨·입고 일정,
수록 카드 도감과 구매 가이드를 한 페이지에 모은 정적 사이트입니다.
프레임워크 없이 HTML/CSS/JS로 동작하며, 지도는 **카카오맵 JavaScript SDK**, 주변 매장은 **카카오 장소 검색(Places)** 으로 조회합니다.
로고는 패밀리 브랜드(복지모아)의 벤토 그리드 심볼 형태를 그대로 쓰고 색만 포켓몬카드모아 브랜드(네이비 + 옐로)로 바꿨습니다.

## 3. 주요 기능

### 1번 탭 — 동네에서 찾기 (v2 첫 화면)
- **실제 지도**: 카카오맵 JavaScript SDK(`autoload=false` → `kakao.maps.load`) 타일 (도로·건물·지명·카카오 장소 POI 그대로)
- **지역 선택 (전국)**: `시/도`(17개) → `시/군/구` 2단 드롭다운과 **동네 이름 검색**(예: 판교, 해운대, 제주시). 첫 방문(저장값 없음)의 기본값은 서울 광화문(37.5759, 126.9768)이며, 그 뒤에는 **마지막으로 찾은 자리에서 시작**합니다(v4.35). 지역을 바꾸면 지도가 그 좌표로 이동하고 주변 매장을 새로 조회합니다. 232개 항목(전국 230개 시·군·구)의 중심 좌표는 각 **시·군·구청** 좌표(OpenStreetMap Nominatim, 2026-11-20 확인)이며, 목록에 없는 동네·역·건물 이름은 **카카오 장소 검색**으로 그 자리에서 찾아 지도를 엽니다
- **마지막 검색 위치 기억(v4.35)**: 지역 선택·동네 검색·`🔍 선택 지역 찾기`·`◎ 내 위치로 찾기`·지도 드래그로 찾은 자리를 브라우저에 저장(`localStorage` `pokemoa.lastLocation` — 좌표·반경·시/도·지역 id·라벨·방식·시각)해, 페이지를 다시 열면 **서울이 아니라 그 자리에서 바로 조회**합니다. 복원되면 토스트로 `지난번 찾은 ‘경북 · 포항 · 북구’ 자리에서 시작합니다.` 라고 한 번 알려 줍니다. 저장값이 손상됐거나 없는 지역이면 조용히 기본값(서울)으로 돌아갑니다
- **실시간 주변 매장**: 지역 선택 또는 **내 위치로 찾기**(브라우저 Geolocation) →
  카카오 장소 검색 `categorySearch('CS2')`를 반경에 맞게 나눠 **병렬 조회**하고(3km 이하는 중심 1곳 3페이지, 5km·20km는 중심 + 방위 오프셋 격자), `id` 중복 제거·실제 거리 필터 후 빠진 브랜드는 브랜드별 `keywordSearch`로 보충해 **편의점 4사(GS25·CU·세븐일레븐·이마트24)**만 남겨 표시(그 밖의 브랜드·업종은 제외). 3km 조회는 보통 1초 이내, 5km·20km 격자 조회는 2~4초(8초 넘으면 스냅샷으로 먼저 표시)
- **로딩 UI**: 카카오맵 지도 → 카카오 장소 검색 2단계 진행률 바 + 스피너 + "실제 지도와 주변 매장 위치를 불러오는 중..." 안내,

## 4. 실시간 중계 — 집 태블릿 실재고 (v3.8)

매장별 **실제 재고 수량**이 필요할 때 쓰는 선택 기능입니다. 사이트는 정적 Pages라 편의점 앱 API를 직접 부를 수 없어서,
집 태블릿이 대신 조회해 주는 작은 서버(`relay/server.js`)를 두고 지도가 그 서버를 통해 실재고를 받아 옵니다.

### 켜는 법 (태블릿 · Termux)
```bash
pkg install nodejs cloudflared        # 한 번만 (cloudflared가 안 보이면 `pkg install tur-repo` 뒤 다시)
node server.js                        # relay/ 폴더에서 — http://127.0.0.1:3100
cloudflared tunnel --url http://127.0.0.1:3100   # 출력된 https://….trycloudflare.com 이 중계 주소
```
